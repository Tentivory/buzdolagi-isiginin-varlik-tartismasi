# Buzdolabı Işığının Varlık Tartışması

> Kapak kapalıyken içerideki ışık yanıyor mu?
>
> Bu depo bir şaka değildir. Bu depo bir kamu hizmetidir.
> Işık vatandaştır. Vatandaş sayılmadan kapağı kapatamazsınız.

## Resmi amaç

T.C. Buzdolabı Işığı Varlık Tartışması Komisyonu, evlerde gece 03:17'de açılan kapakların ardında kalan ontolojik boşluğu doldurmak üzere kurulmuştur.

- Gözlem yoksa yokluk kanıtı mıdır?
- Ampul maaş almadan yanmaya devam eder mi?
- Raf 2 tanıklık yapabilir mi, yoksa sadece yoğurt mu taşır?

Bu sorulara **kesin**, **nihai** ve **ertesi celsede değişecek** cevaplar üretiriz.

## Çalıştırma

```bash
python3 komisyon.py
```

Program:
1. Beş kişilik heyet kurar.
2. Gözü olmayan tanıkları dinler.
3. Içtihat katsayısıyla oy kullanır.
4. Kapağı **açmadan** hüküm verir. (Çünkü kapağı açmak delili yok eder.)

Bağımlılık yoktur. Sadece Python 3. Standart kütüphane yeter. Buzdolabı zorunlu değildir ama tavsiye edilir.

## Yasal uyarı

Bu yazılımın ürettiği kararlar:

- elektrik faturasını düşürmez,
- kapağı açıp bakmanızı yasaklar (çünkü bilim bozulur),
